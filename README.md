# dev-workflow

Скилл для ИИ-агентов (Claude Code, Codex): регламент разработки через спецификацию и TDD.
Агент сначала договаривается, что делать, потом пишет проверку, потом код, и подтверждает результат реальным выводом команд, а не обещаниями.
Опасные действия (удаление, `push --force`, изменения `main`, деплой) он выполняет только с вашего согласия.

## С чего начать

- **[Коротко для новичка](docs/коротко-для-новичка.md)** — что это и как пользоваться, на 2–3 минуты.
- **[Подробная объяснялка](docs/подробная-объяснялка.md)** — всё о скилле простыми словами.
- **[История изменений](dev-workflow/CHANGELOG.md)**

## Установка

Скопируйте папку `dev-workflow/` (только её, без `docs/`) в одно из мест:

- `~/.claude/skills/dev-workflow` (на Windows `%USERPROFILE%\.claude\skills\dev-workflow`), чтобы скилл работал во всех проектах;
- `.claude/skills/dev-workflow` внутри проекта, чтобы он работал только там.

Нужны `git` и `bash` (на Windows это Git Bash из Git for Windows). `jq` желателен, но не обязателен.

Проверить защитные скрипты:

```bash
bash dev-workflow/scripts/selftest.sh
```

## Структура

```
dev-workflow/          сам скилл
  SKILL.md             ядро: правила, классы задач, гейты, маршрут
  references/          справочники по фазам (открываются по мере надобности)
  templates/           шаблоны файлов задачи
  scripts/             сторож и проверки коммитов
  evals/               сценарии проверки поведения агента
docs/                  объяснялки для людей (в установку не входят)
```
